# Edge Atlas

A static, responsive dashboard that turns `main.tex` into a searchable comparison of on-device AI models for smartphones.

## Run locally

Open `index.html` directly in a browser, or use a simple static server.

## Publish on GitHub Pages

1. Create a GitHub repository and push these files.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and the `/ (root)` folder, then save.
4. GitHub will provide the public URL under the Pages settings.

The site has no build step or server dependency.
